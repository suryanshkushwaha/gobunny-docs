Define every service your business offers, then choose which properties offer
each one.

A service is anything a guest can request from their room: room cleaning, extra
towels, a wake-up call, a plumbing repair. You write each service once here.
Every property draws from this list.

Go to **Master Setup → Services**.

## Quick start

1. Review the seven services GoBunny created for you.
2. Edit their wording, or add your own.
3. Open **Property availability** and turn on the services each property
   offers.
4. Set prices on the property's own Services tab.

## The two tabs

| Tab | Use it to |
| --- | --- |
| **Services** | Write the name, category, and description of each service. These apply everywhere. |
| **Property availability** | Turn each service on or off, property by property. |

## What you start with

GoBunny creates seven services when you sign up.

| Service | Category |
| --- | --- |
| Room Cleaning | Housekeeping |
| Extra Towels | Housekeeping |
| Fresh Linens | Housekeeping |
| AC Issue | Maintenance |
| Plumbing Issue | Maintenance |
| Luggage Assistance | Front Desk |
| Wake-up Call | Front Desk |

Edit them, delete the ones you do not offer, and add your own.

## Add a service

1. Select **Add service**.
2. Enter a **Service name**, such as `Airport Transfer`.
3. Choose a **Category**.
4. Write a **Description**. Guests read this, so describe what they get.
5. Select **Add service**.

The new service appears on every property, switched off. Turn it on for the
properties that offer it.

### Categories

Choose from **Housekeeping**, **Maintenance**, **Front Desk**, **Laundry**, or
**Other / Custom**.

The category decides which team receives the request. A guest asking for extra
towels reaches housekeeping; a guest reporting a blocked drain reaches
maintenance. Nobody gets requests that are not theirs.

Category also groups the services on the guest's screen.

<Callout title="Good to know">

Choose the category by who does the work, not by what the
guest calls it. Anything that does not fit belongs in **Other / Custom**,
which reaches your front desk.

</Callout>

## Edit a service

Select the pencil icon beside any service.

The name and description change on every property at once. Prices do not live
here — each property sets its own.

## Delete a service

Select the bin icon, then confirm.

Deleting removes the service from every property. This cannot be undone. To
stop offering a service at one property only, switch it off in **Property
availability** instead.

## Property availability

Open the **Property availability** tab for a grid: your services down the side,
your properties across the top.

Tick a box to offer that service at that property. Clear it to stop.

Each tick matches the **Enabled** switch on that property's own Services page.
Change it in either place.

### Turning a service off

Clearing a box asks when the service should come back:

| Choice | Comes back |
| --- | --- |
| **Until Tomorrow** | Tomorrow morning |
| **In 1 Hour** / **In 2 Hours** / **In 4 Hours** | After that long |
| **Until End of Day** | Tonight |
| **Custom Date & Time** | When you choose |
| **Indefinitely** | Only when you turn it back on |

Use the timed options for a service that is briefly unavailable — a spa that
closes at 6pm, laundry that stops on Sundays. The service returns on its own,
so nobody has to remember.

A scheduled return shows under the box as a small amber note.

<Callout title="Good to know">

Return times follow the property's own time zone, not
yours. "End of day" at a property in another country means that property's
evening.

</Callout>

## Prices

Prices are set per property, not here — the same service can cost different
amounts at two hotels.

To set one, open the property, go to its **Services** tab, and select **Edit
price**. Leave it blank to offer the service free.

→ [Property services](/properties/services)

## What guests see

A guest sees only the services switched on at their property, grouped by
category, in the order you set on that property's Services tab.

Each one shows its name, description, and price. Free services show no price.

→ [Guest portal: Services](/guest-portal/services)

## Troubleshooting

| Problem | Fix |
| --- | --- |
| A service is missing from a property | Open **Property availability** and tick its box. |
| The availability grid is empty | Add a property first. Properties receive your services automatically. |
| A service shows a dash instead of a checkbox | That property has no setting for it yet. Reload the page. |
| Guests cannot see a service you turned on | Check the property's **Settings** tab has **Guest Services** switched on. |
| A service came back on its own | It had a scheduled return time. Turn it off again and choose **Indefinitely**. |

Recommend the places you would send a guest to — restaurants, viewpoints,
pharmacies — and choose which properties show each one.

Go to **Master Setup → Local Guides**.

## Quick start

1. Add the places you recommend.
2. Paste a Google Maps link for each one.
3. Open **Property availability** and turn on the guides each property shows.

## The two tabs

| Tab | Use it to |
| --- | --- |
| **Guides** | Write each recommendation. Titles, tips, and links apply everywhere. |
| **Property availability** | Turn each guide on or off, property by property. |

## Add a guide

1. Select **Add guide**.
2. Fill in the fields below.
3. Save.

| Field | Notes |
| --- | --- |
| **Name** | The name of the place, as a guest would search for it. |
| **Category** | Groups the guide on the guest's screen. |
| **Description** | One or two lines on why you recommend it. |
| **Insider tip (optional)** | The thing only a local knows. Order the tunacado on rye. |
| **Google Maps URL** | Paste the share link from Google Maps. This becomes the guest's one-tap directions. |
| **Image URL (optional)** | A web address for a photo. |

### Categories

**Food & Drink**, **Places to Visit**, **Shopping**, **Essentials**,
**Activities**, **Nightlife**, and **Other**.

Guests browse by category, so put the pharmacy and the ATM in **Essentials**
where someone looking for them will find them.

<Callout title="Good to know">

The insider tip is what makes this worth reading. A guest
can find a restaurant list anywhere. They cannot find out which table to ask
for.

</Callout>

### Getting the Google Maps link

1. Find the place in Google Maps.
2. Select **Share**.
3. Copy the link.
4. Paste it into **Google Maps URL**.

GoBunny only accepts Google Maps addresses. A guest taps it and their phone
opens directions.

## Edit or delete a guide

Select the pencil icon to edit, or the bin icon to delete.

Edits apply at every property showing that guide. Deleting removes it from all
of them and cannot be undone. To drop a guide at one property only, switch it
off in **Property availability**.

## Property availability

Open the **Property availability** tab for a grid: your guides down the side,
your properties across the top.

Tick a box to show that guide at that property.

This matters most when your properties are in different neighbourhoods. A café
two streets from one hotel is no use to a guest across the city.

Clearing a box takes the guide down at that property straight away. Tick it
again to bring it back.

<Callout title="Good to know">

Guides switch on and off immediately — there is no timer to
bring one back later. If a place closes for a fortnight, clear the box and
put a note in your own calendar to tick it again.

</Callout>

## Order

Set the order guests see on the property's own **Local Guide** tab, by dragging
the guides. Put your strongest recommendation at the top of each category.

→ [Property local guide](/properties/local-guide)

## What guests see

The **Guide** tab of the guest portal shows the guides switched on at that
property, grouped by category, in the order you set.

Each one shows its name, description, insider tip, photo, and a directions
link.

→ [Guest portal: Guide](/guest-portal/guide)

## Troubleshooting

| Problem | Fix |
| --- | --- |
| The link is rejected | GoBunny accepts Google Maps addresses only. Use **Share** in Google Maps and copy that link. |
| A guide is missing at one property | Open **Property availability** and tick its box. |
| No guides show to guests | Check the property's **Settings** tab has **Local Guide** switched on. |
| The availability grid is empty | Add a property first. |
| A photo does not load | The image address is wrong or the host blocks it. Try another. |

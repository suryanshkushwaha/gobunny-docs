What is new in GoBunny, what improved, and what was fixed.

The changelog is not a sidebar link. Open it from the **What's new** dialog,
using **View release notes**.

## What is on the page

A badge in the header shows the version you are on.

Each release below is a card.

| Element | Meaning |
| --- | --- |
| Title | A short name for the release. |
| Version badge | For example `v0.0.5`. The one you are on is also marked **Current**. |
| Summary | A sentence or two on what the release is about. |
| Date | When it went out. |
| **New** | Things that did not exist before. |
| **Improved** | Things that already existed and got better. |
| **Fixed** | Problems that are now solved. |

A release with nothing in one of those groups says "No changes in this area."

## The What's new dialog

After GoBunny is updated, the dialog appears once the next time you open the
dashboard, with the version, the summary, and the highlights.

**View release notes** opens this page. Closing the dialog marks that version
as seen, so it will not reappear on your other devices.

<Callout title="Good to know">

It appears once and stays gone. There is nothing to keep
dismissing.

</Callout>

Everyone can read the changelog, whatever their role.

Every dashboard page sits in the same frame: a sidebar on the left, a header
across the top, and the page in the middle.

This guide covers the frame, so the other guides can cover the pages.

## The sidebar

Your business logo and name sit at the top. Select them to return to the
dashboard.

Below that, links are grouped. You see only the groups your role allows.

### Operations

| Link | Opens |
| --- | --- |
| **Properties** | Every property you can reach. |
| **Guest Requests** | Your live queue. A red count appears when there is open work you can act on. |

There is no **Dashboard** link. The overview page still exists — select your
business logo at the top of the sidebar to reach it.

→ [Dashboard overview](/dashboard/overview)

### Master Setup

Build once for the whole business, then choose which properties offer what.

| Link | Opens |
| --- | --- |
| **Services** | Everything a guest can request. |
| **Menus** | Your dishes, drinks, and menus. |
| **Local Guides** | The places you recommend nearby. |

### Platform Setup

| Link | Opens |
| --- | --- |
| **Branding** | How the guest portal looks. |
| **QR Customization** | How your QR codes look. |
| **Integrations** | Telegram notifications. |
| **Domain** | Your own web address for guest portals. |

### Administration

| Link | Opens |
| --- | --- |
| **Team** | Invite teammates and set their access. |
| **Audit Logs** | What changed, and who changed it. |
| **Settings** | Your profile and your business details. |

**Sign out** is at the bottom.

### Collapse the sidebar

Select the toggle at the top left of the header. The sidebar shrinks to icons.
Hover an icon to see its name. Select the toggle again to expand it.

## The header

| Element | What it does |
| --- | --- |
| Sidebar toggle | Collapses or expands the sidebar. On a phone it slides the sidebar in. |
| Property name | Inside a property, this becomes a dropdown for switching properties. |
| **Search commands** | Opens search. Shows `⌘ K` on a Mac and `Ctrl K` elsewhere. |
| Theme switcher | Light or dark. |

The header stays put while the page scrolls.

## Inside a property

Opening a property changes the sidebar. The account-wide links are replaced by
that property's tabs:

**← All properties**, then Rooms, Menu, Services, Local Guide, QR
Customization, Branding, and Settings.

The property you are working on is named in the header. Use that dropdown to
jump to the same tab in another property — from the Beach House **Menu**
straight to the City Hotel **Menu**.

<Callout title="Good to know">

Each tab has its own web address. Bookmark the one you open
every morning, or send it to a colleague with the same access.

</Callout>

## Search

Press `Ctrl + K`, or `⌘ K` on a Mac. You can also select the search box in the
header.

Type to jump to:

- Any tab of the property you are in
- Any other property, or **Create new property**
- Any account-wide page: Dashboard, Guest Requests, Properties, Master
  Services, Branding, QR Customization, Domain, Integrations, Team, Audit Logs,
  Settings

Only places your role can reach are listed.

## What's new

After GoBunny is updated, a **What's new** dialog appears once, with the version
and a short summary of the changes.

Select **View release notes** for the full list. Closing it marks the release as
seen on all your devices.

→ [Changelog](/administration/changelog)

## Live request alerts

Wherever you are in the dashboard, a new request you have access to will:

1. Raise the red count beside **Guest Requests**
2. Play a short sound
3. Show a pop-up card with the property, room, and a summary

Select the pop-up to open the queue.

→ [Guest requests](/dashboard/guest-requests)

## On a phone

The header is more compact and search collapses to an icon. The sidebar slides
in and closes once you pick a destination. Editors with a side-by-side preview —
Branding and QR Customization — move the preview behind a **Preview** button.

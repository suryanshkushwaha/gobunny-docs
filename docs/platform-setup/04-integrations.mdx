Get guest requests in Telegram, so your team does not have to watch the
dashboard.

Go to **Platform Setup → Integrations**.

## Connect Telegram

The connection is **yours**, not the property's. You connect your own Telegram
account and receive notifications for every property you can reach.

Each teammate connects separately.

1. Select **Connect Telegram**. Telegram opens in a new tab.
2. Press **Start** in Telegram.
3. Come back to GoBunny. The card reads **Connected** with your Telegram
   username.

<Callout title="Good to know">

You cannot connect Telegram for a teammate. Send them here
and let them do it — the messages go to their private chat.

</Callout>

## Choose what your messages contain

| Setting | You get |
| --- | --- |
| **Updates and action buttons** | The full message plus buttons to claim, start, complete, or cancel. |
| **Updates only** | The message, no buttons. |

## What a notification looks like

Each message leads with the status:

- A status icon and label — ⏳ Pending, 🛠️ In Progress, ✅ Completed, ❌
  Cancelled
- The room and property
- For services: the name, category, and price if there is one
- For orders: the items with quantities, the total, and the delivery time
- The guest's note, if they left one
- Buttons, if your setting includes them

## The buttons stay correct

- Press a button in Telegram and the dashboard updates at once.
- Change a request in the dashboard and the original Telegram message is
  rewritten, so its status line stays right.
- When a request closes, the buttons disappear from everyone's message.
- If your access to a property changes, the buttons are worked out again on the
  next update.

You never end up looking at a **Complete** button on work that finished twenty
minutes ago.

## Which buttons you get

The same as your dashboard.

| Role | Buttons |
| --- | --- |
| Owner, Admin, Property manager, Services manager | Start, Complete, and Cancel. |
| Front desk, Housekeeping, Maintenance, F&B manager | Claim, then Complete or Unclaim once it is yours. |
| Read only | No Telegram notifications at all. |

## Which requests you get

The same routing as the dashboard queue, so each team only gets its own work.

| Role | Receives |
| --- | --- |
| Owner, Admin, Property manager | Every order and service request |
| Services manager | All service requests |
| F&B manager | Food and drink orders |
| Housekeeping | Housekeeping and Laundry |
| Maintenance | Maintenance |
| Front desk | Front Desk, Other, and anything uncategorised |
| Read only | Nothing |

Property access narrows this further.

## Disconnect

Select **Disconnect**. Notifications stop at once, and you can reconnect
whenever you like.

Removing someone from the team also ends their Telegram connection.

## Limits

- Notifications are private messages. GoBunny does not post into groups or
  channels.
- One Telegram account per person.
- The connection link works once and expires quickly.
- Everything done from Telegram appears in
  [Audit logs](/administration/audit-logs) marked **Telegram**, so you
  can tell it apart from dashboard work.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| **Connect Telegram** is greyed out | Telegram is not switched on for your business. Ask an owner to arrange it with GoBunny. |
| Pressing **Start** does nothing | The link expired. Return to GoBunny and select **Connect Telegram** again. |
| No notifications arrive | Check the card says **Connected**, that your role receives that kind of request, and that you can reach that property. |
| No buttons on your messages | Your setting is **Updates only**. Switch to **Updates and action buttons**. |
| A dashboard change did not update an old message | Very old messages cannot be rewritten. New ones will stay in step. |
